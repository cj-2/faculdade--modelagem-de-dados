# O que é um Banco de Dados?

## Conceito

Conjuntos de informações, organizados de forma lógica e organizada.

## Importância dos Bancos de Dados

Persistência de dados para tomadas de decisões e valor.

## O que é um Sistema Gerenciador de Banco de Dados?

É a ferramenta de gerenciamento do banco de dados, responsável pelas ações 
de persistência, manipulação e consultas de dados, que se comunica por uma 
"linguagem padrão", no caso dos bancos relacionais.

## Tipos de Banco de Dados

### Hierárquico

Parte de um nó pai, se dividindo em nós filhos, de forma hierárquica, funcionando
como o sistemas de pastas de um SO como o explorer do Windows ou o nautilus do Ubuntu.

**Desvantagens:**

- Possui implementação complexa
- Difícil de gerenciar.
  

### Modelo de Rede

Trabalha com nós como o modelo hierárquico.

**Vantagens**

- Simplicidade conceitual
- Gerenciamento em grande escala
  
**Desvantagens**

- Complexidade
- Falta de independência entre as entidades.

### Relacional

Mais utilizado e mais comum do mercado.

- Independência estrutural.
- Modelagem mais simples.

### Orientado a Objetos

Baseado no paradigma orientado a objetos.
