# História dos Banco de Dados

## Evolução Histórica

### 1960

- Surgimento dos primeiros bancos de dados eletrônicos. 
- Criação do IMS, o banco de dado hierárquico da IBM.
- Aparecimento dos primeiros sistemas de bancos de dados de redes.

### 1970

- Surgimento dos bancos de dados relacionais.

### 1980

- Surgiu a linguágem SQL, que "padronizou" a liguagem dos bancos de dados relacionais.
- Surgiu sistemas de banco de dados orientados a aplicações (espacial, cientifico, de engenharia...)

### 1990

- Surge os: Data mining, data warehousing, bancos de dados multimídia e bases de dados Web.
- Primeiros protótipos de bancos de dados orientados a objetos.

### 2000

- Marcado pelo gerenciamento de dados de fluxo e mineração
- Mineração de dados e suas aplicações
  - XML
  - Integração de dados
  - Redes Sociais
  - Computação em nuvem
  - Sistemas de informação globais
