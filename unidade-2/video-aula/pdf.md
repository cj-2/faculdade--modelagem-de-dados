## Modelos de dados

Um modelo é a representação abstrata e simplificada de um sistema real que pode ser
pensado como um fluxograma que ilustra a relação entre os dados.

## Requisitos do Sistema

São os artefatos que determinam o que o sistema deve fazer.

## Regras de Negócio

Uma regra de negócio é independente do paradigma de modelagem, software ou hardware.
É uma regra do mundo real.
